玉桂狗专注台 · PWA 部署说明（v4）
================================
把本文件夹里的文件（除 README.txt 外）全部上传到 GitHub 仓库 cinnamoroll-workspace 的根目录，覆盖旧文件：
  index.html  manifest.webmanifest  sw.js
  icon-192.png  icon-512.png  icon-maskable-512.png  apple-touch-icon.png  favicon-64.png

更新顺序（很重要）：
1. 先在「数据最完整」的那台设备上打开新版（等 1~2 分钟部署完成后打开链接；提示刷新就点确定）。
2. 立刻在左栏点「⬇ 导出备份」留一份文件。
3. 再依次打开另外的设备。
